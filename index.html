Data Sources

This deployment of AstriaGraph is a static build hosted on GitHub Pages. Object data is fetched on a fixed schedule from the two sources below and republished as static files; there is no live backend or orbit-determination pipeline behind this view.

  • CelesTrak (celestrak.org) — orbital elements and operational status for active satellites.
  • Space-Track.org / USSTRATCOM (space-track.org) — the comprehensive on-orbit cataloged debris population.
  • Optional analytics: AstriaGraph uses Amplitude to receive aggregate interaction events such as filter selections, object counts, data mode, and source labels. Object names and catalog identifiers are not sent.

Orbit Determination

This deployment does not run orbit determination itself; the elements shown are taken as-is from the sources above. The broader AstriaGraph project this fork descends from includes an open-source OD library, based on the Orekit astrodynamics framework, used elsewhere to fit orbits from radar and telescope tracking data. The OD source code is available at ut-astria/orbdetpy.

Visualization

Resident space object data obtained from the sources listed above are stored internally as Cartesian vectors in the J2000 reference frame. Objects and orbits are visualized using the equations of motion of the Kepler two-body problem. In order to reduce computational cost to the browser, perturbations from Earth oblateness, third bodies, atmospheric drag, solar radiation pressure etc., are not taken into account. The source code for this deployment is available at paulhugel/AstriaGraph, a fork of the original ut-astria/AstriaGraph.
